# Handoff: continuing vol-wheel on the laptop (Claude Cowork or Claude Code)

The project's memory lives in this repo, not in any one chat:

| File | What it holds |
|---|---|
| `CLAUDE.md` | Standing decisions, Jordan's thesis and goals, every backtest finding so far, how the code works |
| `config/rules.yaml` | Every threshold, the universe, and all backtest variants |
| `docs/backtest/report.md` | Latest backtest tables (generated by the `backtest` workflow) |
| Claude Docs artifact `b35fd311-9607-4176-9b14-4bc53847457f` | The "Volatility Wheel + LEAP Strategy Rulebook" |

Any new session that reads those files knows what this one knew. The full chat history isn't
needed. Its conclusions are already in `CLAUDE.md`.

## Why move to the laptop

- **YouTube and X are blocked here.** This cloud session's network policy blocks YouTube, and the
  sandbox can't reach CBOE or Yahoo either. On the laptop, Claude can use your browser (Claude in
  Chrome) or `yt-dlp` to pull video transcripts.
- **Backtests can run locally** in about a minute, instead of a GitHub Actions round-trip each time.

## Steps

1. Install git and Python 3.11, then clone the repo:
   `git clone https://github.com/joellis7777/vol-wheel.git`, then
   `cd vol-wheel && pip install -r requirements-dev.txt`.
2. Make a **private** research folder *outside* the repo, e.g. `~/vol-wheel-research/`, with
   `sources/` (raw transcripts) and `notes/` (summaries). This repo is public:
   - Full transcripts are other people's content and shouldn't be republished here.
   - Your positions, balances and trade journal must never go in the repo.
3. In Claude Cowork, create a project named "vol-wheel" and attach both folders.
   (Claude Code in a terminal opened in `vol-wheel/` works the same way, because it reads
   `CLAUDE.md` automatically.)
4. Install the tools that let the session reach the sources:
   - the Claude in Chrome extension, for YouTube and X (Soliel's pinned "Options Comprehensive
     Mega Thread");
   - or `pip install yt-dlp`. Then
     `yt-dlp --write-auto-subs --sub-langs en --skip-download -o "%(upload_date)s %(title)s" <URL or channel URL>`
     downloads a whole channel's subtitles without the videos.
5. Paste the prompt below as the first message.
6. Ask for one batch of videos at a time (10–20). tastylive alone has thousands of hours, so
   point it at the research segments first (Market Measures, Options Jive, "Best Practices",
   anything with backtest studies). For Soliel, start with the pinned mega thread, then videos
   from newest to oldest.

```
You're picking up the vol-wheel project: an options scanner, phone dashboard and backtester for

  1. vol-wheel/CLAUDE.md in full: standing decisions, my thesis and goals, every backtest finding

  3. vol-wheel/docs/HANDOFF.md (this setup).
Then summarize back to me, in about 15 bullets, the strategy as it stands, the open questions and
what the backtests have shown, so I can check you have it right.

Working style: I want to discuss strategy and build in the same session. Push back, flag conflicts
with my standing decisions, and propose tests. Don't just implement. Every threshold goes in
rules.yaml. The repo is public: no account data, positions or balances ever, and no full
third-party transcripts.

Research brain (do this after the summary, in batches I approve):

  X "Options Comprehensive Mega Thread"), and Tom Sosnoff / tastylive (start with Market

First open questions to work on (also in CLAUDE.md):

```
